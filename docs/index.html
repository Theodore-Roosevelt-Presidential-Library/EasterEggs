Add it to the site

One tag in Google Tag Manager: a Custom HTML tag that fires on All Pages.

<script src="https://delight.labs.trlibrary.com/delight.js" async></script>

On a normal day the tag only loads a small file that checks the date. The animation's own file loads only on the day it plays. Delights never play on donate, checkout, ticketing, account or admin pages, or inside an embedded frame.

?delight=tr-birthdayAdd to any trlibrary.com address to play one delight right away, on any day.
?delight-date=2027-07-04Act as if it were that date.
?delight=offTurn delights off in this browser for the rest of the visit (?delight=on turns them back on).
data-positionOn the script tag: top (default), bottom-left or bottom-right. The card moves on its own to stay clear of anything pinned to the screen, like a ticket button or chat bubble.
data-excludeOn the script tag: a pattern of page paths to skip, replacing the default list.
AnalyticsEach delight pushes delight_view, delight_click and delight_close to the GTM data layer with delight_id.
